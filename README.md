# 로또 랩 · 대한민국 로또 6/45

당첨 이력 통계, 조건별 번호 생성, 추천 기록 저장, 당첨 확인을 제공하는 개인용 프로그램입니다.
Python + Streamlit + SQLite로 구성되며 데이터는 이 폴더의 `data/lotto.sqlite3`에 저장됩니다.

## 실행

현재 작업 PC에는 필요한 라이브러리를 설치한 `.venv`가 있습니다.
GitHub에서 새로 내려받은 경우 아래의 새 PC 설치 명령을 먼저 실행하세요.

1. `start.cmd`를 더블 클릭합니다.
2. 브라우저에서 `http://127.0.0.1:8501`을 엽니다.
3. 종료할 때 실행 창에서 `Ctrl+C`를 누릅니다.

PowerShell에서는 다음 명령으로 실행할 수도 있습니다.

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

새 PC에서는 정상 동작하는 Python 3.12 이상으로 환경을 설치하세요.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

`start.cmd`와 `start.ps1`는 로컬 모드로 실행하고 `127.0.0.1`에서만 접속할 수 있습니다.
로컬 SQLite 파일을 보존하면 추천 기록도 유지됩니다.
직접 실행 시에도 영구 로컬 저장을 사용하려면 PowerShell에서 `$env:LOTTO_LOCAL_MODE = '1'`을 먼저 설정하세요.
기본 실행은 웹 체험 모드로, 접속마다 분리된 임시 DB를 사용합니다.

## 사용

- **대시보드**: 등록된 마지막 회차와 최근 출현 현황.
- **통계 분석**: 본번호 출현 횟수, 미출현 경과 회차, 홀짝·합계·구간·연속번호·번호 쌍 통계.
- **번호 추천**: 균등 무작위, 조건 지정, 통계 가중 추천. 포함·제외 번호, 홀짝, 합계, 게임 간 중복을 지정할 수 있습니다.
- **추천 기록 · 결과**: 추천 당시 설정과 대상 회차를 저장하고, 당첨 이력이 들어오면 등수를 자동 대조합니다. 직접 번호 확인도 가능합니다.
- **과거 검증**: 과거 시점에서 이용 가능했던 기록만으로 고정된 통계 가중 방식과 무작위 방식을 비교합니다. 같은 게임 수로 평가하며, 학습 자료와 대상 회차가 섞이지 않습니다.
- **데이터 관리**: 공식 결과 조회, CSV 가져오기, 회차 직접 등록, 누락 탐지, CSV 백업.

데이터가 없어도 무작위·조건 지정 추천은 사용할 수 있습니다. 공식 수집 CSV 동봉본이 있으면 빈 DB에 한 번 가져옵니다.
동봉된 데이터의 범위는 `data/SOURCE.md`를 확인하세요. 실시간 최신 여부는 자동 보장하지 않습니다.

## 데이터 입력과 갱신

공식 결과: https://www.dhlottery.co.kr/lt645/result

공식 사이트 결과 페이지에서 사용하는 조회 경로의 실제 응답을 확인해 구현했습니다.
이는 공식 공개 API나 안정성 보장 계약이 아닙니다. 사이트 변경·접근 제한·네트워크 장애 시 CSV 또는 직접 등록을 사용하세요.
사용자가 가져오기 버튼을 누를 때만 조회하며, 백그라운드 예약 수집은 하지 않습니다.
요청 사이에 간격을 두며, 한 응답에 포함된 여러 회차를 재사용합니다. 최초 전체 수집에는 시간이 걸릴 수 있습니다.
요청 범위의 모든 회차가 검증된 후에만 저장합니다. 기존 기록과 충돌하면 전체 가져오기를 취소합니다.

CSV 헤더:

```csv
round,date,n1,n2,n3,n4,n5,n6,bonus
```

날짜는 `YYYY-MM-DD`, 인코딩은 UTF-8(BOM 포함 가능) 또는 CP949를 지원합니다.
본번호 6개는 중복 없는 1~45 정수, 보너스번호는 본번호와 다른 1~45 정수여야 합니다.
CSV와 직접 입력 데이터에는 공식 출처 검증 표시를 붙이지 않습니다.
수집 시각은 DB에 UTC로 저장합니다. CSV 내보내기는 당첨 결과 필드만 포함합니다.

명령행 수집 예:

```powershell
.\.venv\Scripts\python.exe -m scripts.import_official --start 1148 --end 1247
```

`data/lotto.sqlite3` 전체를 복사하면 추천 설정과 기록까지 백업할 수 있습니다. DB 백업 시 프로그램을 먼저 종료하세요.

## 추천과 검증의 해석

공정하고 독립적인 추첨에서는 모든 조합의 1등 확률이 `1 / 8,145,060`으로 같습니다.
과거 통계는 미래의 확률을 높이지 않습니다. 홀짝·합계·미출현 조건은 취향에 맞는 조합을 고르는 기능입니다.

통계 가중은 과거 본번호 출현 횟수에 1을 더해 추출 가중치로 사용합니다.
일반 후보 공간에서는 번호를 순차적으로 비복원 추출합니다. 후보 조합이 10만 개 이하이면
조건을 만족하는 후보를 열거한 뒤 조합에 속한 번호 가중치의 합으로 추출합니다.
이 수치는 당첨 확률이 아닙니다. 추천 결과에서 실제 적용 구간과 번호별 출현 횟수를 확인할 수 있습니다.
조건이 지나치게 좁거나 조합 간 중복 제한을 충족하지 못하면 조건 완화를 안내합니다.

통계의 ‘최근 N회’는 등록된 최근 N개 회차를 뜻합니다. 구간에 누락이 있으면 경고합니다.
미출현 경과는 선택 구간 내 마지막 출현 회차와 구간 마지막 회차의 차이이며,
선택 구간에 한 번도 안 나온 번호의 값은 비워 둡니다. 보너스번호는 모든 본번호 통계에서 제외합니다.

과거 검증은 연속 회차에서만 실행합니다. 시드 42를 기준으로 회차와 방식별 별도 시드를 사용해
결과를 재현하며, 같은 회차의 여러 게임은 독립 표본으로 간주하지 않습니다.
평균 일치 개수, 등수별 횟수, 회차별 평균의 변동을 보여주는 탐색 도구입니다.
신뢰구간·수익률·예측 우위는 추정하지 않습니다. 가중치 튜닝이나 모델 학습은 포함하지 않으며,
향후 튜닝 기능을 추가할 때에는 평가용 기간을 별도로 확보해야 합니다.
과거 회차를 대상으로 생성한 추천은 기록에서 연습으로 표시합니다.
